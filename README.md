# Prudhvi Reddy — Personal Portfolio Website 🚀

![Portfolio Banner](public/profile.png)

A modern, high-performance interactive 3D portfolio website built for **Prudhvi Reddy** — Data Specialist, Power Platform Developer, and Software Engineer.

🌐 **Live Website**: [https://prudhvi-portfolio-zeta.vercel.app](https://prudhvi-portfolio-zeta.vercel.app)

---

## ✨ Key Features

* 🎨 **3D Interactive Hexagonal Canvas**: Dynamic particle background with smooth light/dark theme transitions.
* 🌐 **Multilingual Engine**: Native support for **English (EN)**, **Hindi (HI)**, **Japanese (JP)**, and **Arabic (AR)** with Right-to-Left (RTL) mirror handling.
* 🏆 **Certificates & Credentials Modal**: Interactive viewer showcasing professional certifications (Cisco, Anthropic, Oracle, Snowflake, LinkedIn).
* ⚡ **Performance & Motion**: Built with Next.js Turbopack, Tailwind CSS, and Framer Motion micro-interactions.
* 📬 **Contact Form & Social Links**: Quick connectivity links for LinkedIn, X (Twitter), Telegram, and direct email.

## 💻 Local Development Setup

To run this portfolio locally on your machine:

1. **Clone the repository**:
   ```bash
   git clone https://github.com/prudhvi05reddy/prudhvi-portfolio.git
   cd prudhvi-portfolio
   ```

2. **Install dependencies**:
   ```bash
   npm install
   ```

3. **Start the local development server**:
   ```bash
   npm run dev
   ```

4. **Preview**:
   Open `http://localhost:3000` in your web browser.
